# Offline Study AI — школьный AI-помощник для iPhone, работающий без интернета

Нативное приложение на Swift + SwiftUI. Ответы генерирует **локальная языковая модель прямо на iPhone**
(llama.cpp + Metal GPU). После установки модели приложению не нужны интернет, Wi-Fi и мобильная сеть.

**Один раздел для всех предметов.** Отдельных экранов «Биология», «Химия» и т.д. нет: есть один
универсальный чат. Предмет определяется автоматически, по нему подписываются вопросы в истории,
и он же подсказывается модели. Чипы предметов на главном экране просто подставляют пример вопроса.

## 1. Выбор модели и формата (проверка совместимости)

| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| **GGUF + llama.cpp** | Один файл модели, импорт из «Файлов»; Metal-ускорение на GPU iPhone; огромный выбор готовых моделей; mmap — веса не копируются в RAM лишний раз; официальный готовый `llama.xcframework` | C-API, нужна обёртка (уже написана) | ✅ **Выбран** |
| MLX (mlx-swift) | Быстрый, от Apple | Модель — это папка из многих файлов (неудобно импортировать на телефоне), на iOS требует больше памяти | Хорошая альтернатива |
| Core ML | Нативный формат Apple | LLM нужно самому конвертировать и квантовать, мало готовых моделей, сложный KV-кэш | Слишком трудоёмко |

**Модель по умолчанию: Qwen2.5 Instruct (Alibaba, лицензия Apache 2.0)** — одна из лучших маленьких моделей
с хорошим русским языком, официально выложена в GGUF.

| Модель | Файл | Размер | Для каких iPhone |
|---|---|---|---|
| Qwen2.5 1.5B Instruct Q4_K_M | `qwen2.5-1.5b-instruct-q4_k_m.gguf` | ≈1.1 ГБ | 6 ГБ RAM: iPhone 12 Pro, 13 Pro, 14, 14 Plus, 15, 15 Plus |
| Qwen2.5 3B Instruct Q4_K_M | `qwen2.5-3b-instruct-q4_k_m.gguf` | ≈2.1 ГБ | 8 ГБ RAM: iPhone 15 Pro, 16-я и 17-я серии |

Скачать (на компьютере, один раз):
- https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF/tree/main
- https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF/tree/main

Почему не больше: iOS даёт одному приложению примерно 50–65 % физической RAM. Модель 7B (≈4.5 ГБ)
на большинстве iPhone приведёт к принудительному закрытию приложения. На iPhone с 4 ГБ RAM
(iPhone 11, 12, 12 mini, SE) запускайте только модели до ~1B (например, `qwen2.5-0.5b-instruct-q4_k_m.gguf`)
и ставьте контекст 1024.

Подойдёт и любая другая instruct-модель в GGUF, которую поддерживает llama.cpp: Llama 3.2 1B/3B, Gemma 3 1B/4B,
Phi-3.5 mini, Qwen3 1.7B/4B (для Qwen3 приложение само отключает «режим размышлений»).

## 3. Функции

- **Единый чат** для всех предметов: Markdown, формулы, списки, потоковая генерация с индикатором,
  кнопка «Стоп», «Копировать», «В избранное», продолжение диалога, «Объясни проще», «Дай пример».
- **Режим «Решить задание»**: предмет → дано → решение по шагам → ответ.
- **Фото задания**: камера или «Фото» → распознавание текста на устройстве → проверка/правка → решение.
- **Офлайн-режим**: статусы и кнопка «Проверить офлайн-работу» — реальная генерация короткого ответа
  с замером скорости и состоянием сети в момент теста.
- **AI-модель**: имя, размер, память под веса, параметры, контекст, статус, доступная RAM, свободное место,
  импорт `.gguf` из файла, выбор между несколькими моделями, удаление, загрузка/выгрузка.
- **История** (вопрос, предмет, дата, ответ, поиск, фильтр по предметам) и **Избранное**.
- **Настройки**: тема, размер текста, кратко/подробно, 5–7 / 8–9 / 10–11 класс, контекст, длина ответа,
  креативность, очистка истории, информация о модели, тест офлайн-режима.
- **Производительность**: mmap-загрузка, проверка RAM перед загрузкой, выгрузка модели при
  предупреждении iOS о памяти и при уходе в фон, отмена генерации, ограничение контекста с автоматической
  обрезкой старой истории, повторное использование KV-кэша (продолжение диалога не пересчитывает всё заново).

## 4. Что нужно для сборки

**Вариант А — есть Mac (самый простой):** macOS 14.5+ и **Xcode 16 или новее** (бесплатно в Mac App Store).

**Вариант Б — только Windows:** Xcode работает только на macOS, поэтому собрать .ipa на Windows напрямую нельзя.
Рабочие пути: (1) бесплатная сборка на macOS-сервере GitHub Actions (файл уже в проекте, см. раздел 8) +
установка через Sideloadly на Windows; (2) арендованный облачный Mac (MacinCloud и аналоги); (3) чужой Mac на час.

## 5. Открыть проект в Xcode

1. Распакуйте архив, например в `~/Developer/OfflineStudyAI`.
2. Двойной щелчок по `OfflineStudyAI.xcodeproj`.
3. Xcode сам скачает пакет `llama` (≈60 МБ) — внизу будет «Resolving Package Graph». Нужен интернет **на Mac**,
   только для сборки. Если пакет не подтянулся: **File → Packages → Reset Package Caches**.
4. Слева выберите проект **OfflineStudyAI** → таргет **OfflineStudyAI** → вкладка **Signing & Capabilities**:
   - **Team**: нажмите *Add Account…*, войдите своим Apple ID, выберите команду «Ваше имя (Personal Team)»;
   - **Bundle Identifier**: замените `com.tegg54751.offlinestudyai` на уникальный, например `com.ivanov.offlinestudyai`.

## 6. Сборка и установка на физический iPhone (бесплатно, через Apple ID)

1. Подключите iPhone к Mac кабелем, на телефоне нажмите **«Доверять этому компьютеру»**.
2. На iPhone (iOS 16+): **Настройки → Конфиденциальность и безопасность → Режим разработчика → Вкл**, перезагрузка, подтвердить.
   (Пункт появляется после первого подключения к Xcode.)
3. В Xcode вверху выберите схему **OfflineStudyAI** и ваш iPhone как устройство.
4. Нажмите **▶ (Cmd + R)**. Первая сборка займёт пару минут.
5. При первом запуске iPhone скажет «Ненадёжный разработчик»: **Настройки → Основные → VPN и управление
   устройством → ваш Apple ID → Доверять**. Запустите приложение снова.

> Схема уже настроена на конфигурацию **Release** — генерация в ней заметно быстрее.

**Симулятор не поддерживается** официальной сборкой llama.cpp (в ней только срез для реального iPhone),
и Metal-ускорения LLM в симуляторе всё равно нет. Если нужен симулятор: соберите xcframework сами командой
`./build-xcframework.sh ios-sim ios-device` из репозитория llama.cpp и подключите его вместо пакета.

## 7. Установка локальной AI-модели (без интернета на iPhone)

1. На компьютере скачайте файл, например `qwen2.5-1.5b-instruct-q4_k_m.gguf` (ссылки в разделе 1).
2. Перенесите его на iPhone любым способом:
   - **AirDrop** с Mac → «Сохранить в Файлы»;
   - **iCloud Drive / флешка USB-C / Google Drive** → приложение «Файлы»;
   - **Mac, Finder**: выберите iPhone → вкладка «Файлы» → перетащите `.gguf` на *Offline Study AI*;
   - **Windows**: приложение *Apple Devices* (или iTunes) → iPhone → «Общий доступ к файлам» → *Offline Study AI* → «Добавить файл».
3. В приложении: **Главная → карточка модели** (или Настройки → Информация о модели) → **«Импортировать модель (.gguf)»**
   и выберите файл. Если вы копировали через Finder/iTunes — модель появится в списке автоматически.
4. Нажмите **«Загрузить в память»** (или просто задайте вопрос — модель загрузится сама).
5. Откройте **Настройки → Офлайн-режим и тест**, включите авиарежим и нажмите **«Проверить офлайн-работу»**.

Приложение никогда не скачивает модель само и не требует интернета.

## 8. Установка без App Store для тестирования

### Способ 1. Xcode (раздел 6)
Самый надёжный. Подходит, если есть Mac.

### Способ 2. Без Mac: GitHub Actions + Sideloadly (Windows)
1. Создайте репозиторий на GitHub и загрузите туда проект (папка `.github` должна попасть в репозиторий).
2. Вкладка **Actions → Build unsigned IPA → Run workflow**. Через 5–15 минут в разделе *Artifacts*
   появится `OfflineStudyAI-unsigned-ipa` — скачайте и распакуйте `.ipa`.
   *Для публичных репозиториев macOS-минуты бесплатны; для приватных расходуется бесплатная квота (macOS-минуты считаются ×10).*
3. Установите на Windows **iTunes (версию с сайта Apple, не из Microsoft Store)** и **Sideloadly** (sideloadly.io).
4. Подключите iPhone кабелем, перетащите `.ipa` в Sideloadly, введите Apple ID, нажмите **Start**.
5. На iPhone: доверьте профиль (Настройки → Основные → VPN и управление устройством) и включите Режим разработчика.

### Способ 3. AltStore (Windows/Mac)
Устанавливает тот же `.ipa`, умеет сам продлевать подпись по Wi-Fi, когда компьютер с AltServer включён.

### Способ 4. Платный аккаунт разработчика (99 $/год)
Подпись на год и TestFlight — установка по ссылке до 10 000 тестировщиков.

## 9. Честно об ограничениях бесплатной установки Apple

- Приложение, подписанное бесплатным Apple ID, **работает 7 дней**. Потом оно перестаёт открываться —
  нужно снова нажать ▶ в Xcode (или переустановить через Sideloadly/AltStore). **Данные и модель при
  переустановке поверх сохраняются**, если не удалять приложение.
- Одновременно не больше **3 приложений** с бесплатной подписью на устройство и не больше **10 App ID за 7 дней**.
- Нельзя публиковать в App Store и раздавать через TestFlight.
- Некоторые возможности (entitlements) бесплатной команде недоступны. Проект намеренно не использует ни одну из них,
  поэтому собирается и с Personal Team.
- Нужен Режим разработчика на iPhone.

## 10. Честно об ограничениях функций в офлайне

- **Точность.** Модели 1.5–3B на телефоне хорошо объясняют темы, но **ошибаются в вычислениях и фактах**
  заметно чаще больших облачных моделей. Ответы по математике и датам нужно проверять. В режиме решения модели
  велено проверять каждый шаг, но гарантий нет.
- **Формулы.** Модель пишет формулы в LaTeX; приложение показывает их как Unicode-текст (`x²`, `√x`, `a/b`, `H₂SO₄`)
  полностью офлайн. Многоэтажные дроби и матрицы рисуются в одну строку. Полную вёрстку LaTeX можно добавить
  офлайн-библиотекой SwiftMath — тогда появится ещё одна зависимость.
- **OCR.** Apple Vision отлично распознаёт печатный и аккуратный рукописный текст на русском и английском,
  но не понимает вёрстку формул. Поэтому после распознавания текст открывается для проверки и правки.
- **Фоновый режим.** iOS запрещает работу GPU в фоне, поэтому при сворачивании генерация останавливается,
  а модель (по настройке) выгружается. При возврате она загрузится заново за несколько секунд.
- **Скорость.** Ориентировочно 15–35 токенов/с для 1.5B и 8–18 токенов/с для 3B на современных iPhone.
  Первая загрузка модели — 2–10 секунд.
- **Нагрев и батарея.** Длинная генерация заметно греет телефон — это нормально для локальных LLM.

## 11. Как заменить AI-движок

Всё приложение работает через протокол `AIService` (`AI/AIService.swift`):

```swift
protocol AIService: AnyObject {
    var backendName: String { get }
    func load(modelAt url: URL, contextSize: Int) async throws -> LoadedModelInfo
    func unload() async
    func generate(turns: [ChatTurn], params: GenerationParams) -> AsyncThrowingStream<AIStreamEvent, Error>
}
```

Напишите класс, например `MLXAIService: AIService`, и замените одну строку в `App/OfflineStudyAIApp.swift`:

```swift
let ai = AIController(service: LlamaAIService(), ...)   // → MLXAIService()
```

## 12. Если что-то не собирается

| Проблема | Решение |
|---|---|
| `No such module 'llama'` | File → Packages → Reset Package Caches, затем Product → Clean Build Folder (Shift+Cmd+K) |
| Ошибка подписи «No profiles» / «Failed to register bundle identifier» | Поменяйте Bundle Identifier на уникальный и выберите Team |
| Ошибка в строке `llama_sampler_init_penalties` | Вы обновили llama.cpp на другую версию: в старых версиях у функции нет первого аргумента `n_vocab` — удалите его |
| Приложение закрывается при загрузке модели | Мало RAM: выберите модель 1.5B/0.5B или контекст 1024, закройте другие приложения |
| «Модель не похожа на GGUF» | Скачан не тот файл (HTML-страница вместо модели). Файл должен весить ~1–2 ГБ |
| Ответы бессвязные | Нужна именно *instruct*-модель, не *base* |
| Xcode 15 не открывает проект | Нужен Xcode 16+ (проект использует синхронизируемые папки) |

## 13. Приватность

Вопросы, ответы, фото и история никуда не отправляются. История хранится в
`Application Support/history.json`, модели — в `Documents/Models` (исключены из резервной копии iCloud).
Единственное сетевое API в коде — `NWPathMonitor`, который лишь показывает на экране «Офлайн-режим»,
включена ли сейчас сеть; он не делает запросов.
